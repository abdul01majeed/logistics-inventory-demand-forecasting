Project Results and Analysis
Project: Logistics Inventory Management and Demand Forecasting
1. Data Cleaning

The project uses Python and Pandas to clean retail transaction records by removing duplicates, handling missing values, converting date formats, and filtering invalid transactions.

2. Exploratory Data Analysis

The analysis investigates:

Top-selling products
Monthly revenue trends
Daily product demand
Product revenue distribution
Relationships between numerical variables
3. Demand Forecasting

A Random Forest Regression model is proposed to estimate product demand using historical sales features.

Model performance is evaluated using:

Mean Absolute Error (MAE)
Root Mean Squared Error (RMSE)
Weighted Absolute Percentage Error (WAPE)
4. Product Clustering

K-Means clustering is applied to group products according to demand and revenue characteristics.

The intended categories are:

High-demand products
Medium-demand products
Low-demand products
5. Inventory Management Applications

The analytical results can support:

Inventory replenishment decisions
Reorder point estimation
Safety stock planning
Warehouse resource allocation
Reduction of excess inventory
6. Conclusion

This project demonstrates how Python-based data analytics and machine learning can support better inventory planning and logistics decision-making.
