Dataset Documentation
Dataset Name

Online Retail II Dataset

Source

UCI Machine Learning Repository

Dataset URL: https://archive.ics.uci.edu/dataset/502/online+retail+ii

Description

The Online Retail II dataset contains historical transaction records from a UK-based online retail business.

It includes:

Invoice number
Stock code
Product description
Quantity purchased
Invoice date
Unit price
Customer ID
Country
Purpose

This dataset is used for:

Retail sales analysis
Demand forecasting
Product segmentation
Inventory management research
Data Processing

The dataset is cleaned using Python and Pandas.

The cleaning process includes duplicate removal, date conversion, cancellation handling, and removal of invalid sales records.

Note

The original dataset is publicly available from the UCI Machine Learning Repository. It is not included in this repository to avoid unnecessary large file uploads. Download it from the original source before running the analysis scripts.
